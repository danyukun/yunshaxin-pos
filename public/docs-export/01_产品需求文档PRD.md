## 二、SaaS平台层 (运营方管理后台)

### 2.1 商户管理

#### 2.1.1 商户入驻
| 功能点 | 详细描述 | 优先级 |
|--------|----------|--------|
| 商户注册 | 品牌名称、联系人、手机号、邮箱 | P0 |
| 资质审核 | 营业执照上传、审核 | P0 |
| 商户信息 | 品牌Logo、品牌介绍、联系电话、地址 | P0 |
| 商户状态 | 启用/停用/欠费/注销 | P0 |
| 商户编号 | 系统自动生成唯一商户ID | P0 |

#### 2.1.2 套餐管理
| 套餐名称 | 价格(年) | 门店数 | 员工数 | 功能范围 |
|----------|----------|--------|--------|----------|
| 基础版 | ¥1,980 | 1家 | 3人 | 收银+订单+客户 |
| 标准版 | ¥3,980 | 3家 | 10人 | 基础+营销+统计 |
| 专业版 | ¥6,980 | 10家 | 50人 | 标准+物流+API |
| 旗舰版 | 定制 | 不限 | 不限 | 全部功能+定制 |

| 功能点 | 详细描述 | 优先级 |
|--------|----------|--------|
| 套餐定义 | 名称、价格、功能权限、门店数、员工数 | P0 |
| 套餐变更 | 升级/降级/续费 | P0 |
| 免费试用 | 15天免费试用期 | P1 |
| 到期提醒 | 到期前30天/15天/7天自动提醒 | P0 |

#### 2.1.3 结算管理
| 功能点 | 详细描述 | 优先级 |
|--------|----------|--------|
| 订单管理 | 商户订单列表、支付状态 | P0 |
| 发票管理 | 发票申请、开具 | P1 |
| 账单明细 | 每笔交易明细 | P0 |
| 自动续费 | 微信/支付宝自动扣款 | P1 |

#### 2.1.4 工单客服
| 功能点 | 详细描述 | 优先级 |
|--------|----------|--------|
| 工单系统 | 商户提交问题工单 | P1 |
| 工单流转 | 待处理→处理中→已完成 | P1 |
| 常见问题 | 平台FAQ知识库 | P1 |
| 在线客服 | 即时通讯客服 | P2 |

### 2.2 微信生态绑定

#### 2.2.1 小程序配置
| 功能点 | 详细描述 | 优先级 |

#### 2.2.2 公众号配置
| 功能点 | 详细描述 | 优先级 |
|--------|----------|--------|

| 模板消息 | 订单通知、进度通知、取衣提醒 | P0 |
| 菜单配置 | 自动配置公众号菜单 | P1 |
| 关注回复 | 自动回复设置 | P1 |
| 消息推送 | 订单状态变更、余额变动、优惠推送 | P0 |

#### 2.2.3 微信支付
| 功能点 | 详细描述 | 优先级 |
|--------|----------|--------|
| 商户号绑定 | 商户绑定自己的微信支付商户号 | P0 |
| 支付渠道 | 小程序支付、公众号支付、扫码支付 | P0 |
| 退款处理 | 原路退回 | P0 |
| 对账功能 | 每日对账单 | P1 |
