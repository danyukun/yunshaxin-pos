## 快速导航

### 核心业务流程

```
客户到店
    │
    ├─ 搜索/新建客户 ──────────────── [下单收银页] ReceiveOrder
    │
    ├─ 录入衣物（品类/服务/价格/照片/瑕疵）
    │
    ├─ 系统自动分配挂点（补位算法）
    │
    ├─ 结账收款（现金/微信/支付宝/会员卡）
    │
    └─ 打印小票 + 水洗唛标签

批次管理
    │
    ├─ 送洗调度 ───────────────────── [送洗管理] WashDispatch（占位）
    │
    ├─ 批次到店 ───────────────────── [批次到店] PickupOrder
    │
    └─ 上挂管理 ───────────────────── [上挂管理] HangManage

客户取衣
    │
    ├─ 查看订单状态 ────────────────── [衣物板块] ClothesStock
    │
    └─ 确认取走 → 释放挂点 → 完成
```

### 挂点生命周期

```
free（空闲）
  │ 下单录入衣物时分配
  ▼
washing（洗涤中）
  │ 确认上架（HangManage）
  ▼
ready（待取）
  │ 客户取衣完成（ClothesStock / PickupOrder）
  ▼
free（释放）
```
