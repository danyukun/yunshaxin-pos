## 目录结构

```
/
├── public/
│   └── docs-export/          # 开发文档（本目录）
├── src/
│   ├── app/
│   │   ├── App.tsx           # 根组件、路由 switch、AppProvider 包裹
│   │   ├── components/
│   │   │   ├── Header.tsx    # 顶部导航栏（搜索、会员选择）
│   │   │   ├── Sidebar.tsx   # 左侧导航栏（主菜单 + 更多弹层）
│   │   │   ├── ImageWithFallback.tsx  # 带降级的图片组件
│   │   │   ├── pages/        # 22 个业务页面组件
│   │   │   └── ui/           # shadcn/ui 组件库（约 35 个）
│   │   └── data/
│   │       └── AppContext.tsx # 全局状态 + 类型定义 + 初始数据
│   └── styles/
│       ├── fonts.css         # Google Fonts 导入
│       ├── globals.css       # 全局基础样式
│       ├── index.css         # Tailwind 主题映射（@theme inline）
│       ├── tailwind.css      # Tailwind 入口
│       └── theme.css         # CSS 变量 token 定义
├── package.json
└── vite.config.ts
```

## 构建配置

- 构建工具：Vite，使用 `@tailwindcss/vite` 插件
- 入口：`src/main.tsx`
- 无后端，所有数据保存在 React state 中（刷新重置）
- 品牌色：`#fd780f`（橙色），在 `theme.css` 中定义为 `--brand`
