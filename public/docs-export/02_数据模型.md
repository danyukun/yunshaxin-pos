## GarmentRecord（衣物记录）

```typescript
interface GarmentRecord {
  id: string;
  label: string;           // 洗涤标签，格式：S01{orderNo}{garmentNo3}{attachNo2}
  type: string;            // 衣物品类名称
  service: string;         // 洗涤服务名称
  price: number;
  color: string;
  brand: string;
  defects: string[];       // 瑕疵列表
  status: GarmentStatus;
  batchId?: string;        // 送洗批次 ID
  warehousingAt?: string;  // 入库时间
  serviceCycleHours?: number;
  isOverdue?: boolean;     // 是否超期
  photos?: string[];       // 收衣照片 URL
  isAttachmentRow?: boolean; // 是否为附件行
  parentLabel?: string;    // 附件所属主件标签
  bindTag?: string;        // 绑定标签（如架位号）
  hookSlotId?: string;     // 关联挂点 ID
  hookSlotLabel?: string;  // 挂点显示名
}
```

**标签格式：** `S01{orderNo}{garmentNo3}{attachNo2}`
- `S01`：门店前缀（固定）
- `orderNo`：订单号（如 `1012569`）
- `garmentNo3`：衣物序号，3位补零（如 `001`）
- `attachNo2`：附件序号，2位补零（如 `00` 表示主件）

## AppOrder（订单）

```typescript
interface AppOrder {
  id: string;
  orderNo: string;
  type: OrderType;
  source: OrderSource;
  customerName: string;
  phone: string;
  address: string;
  garments: GarmentRecord[];
  totalAmount: number;
  receivedAt: string;
  expectedAt: string;
  notes: string;
  tracking: TrackEvent[];   // 操作日志
  messages?: OrderMessage[];
  isHang?: boolean;         // 是否已上架
  compensationAmount?: number; // 退赔金额
  bagNo?: string;           // 袋号（快递单号）
}

interface TrackEvent   { time: string; action: string; operator: string; }
interface OrderMessage { id: string; time: string; content: string; operator: string; }
```

## HookZone & HookSlot（挂点）

```typescript
interface HookZone {
  id: string;
  name: string;
  capacity: number;       // 该区域容纳点位数
  categoryIds?: string[]; // 关联品类；空数组 = 接受所有品类
}

type HookSlotStatus = 'free' | 'washing' | 'ready' | 'collected';

interface HookSlot {
  id: string;
  zoneId: string;
  zoneName: string;
  label: string;         // 显示名，如 "第1层-3"
  status: HookSlotStatus;
  garmentId?: string;
  garmentLabel?: string;
  orderId?: string;
  orderNo?: string;
  customerName?: string;
  garmentType?: string;
  garmentColor?: string;
  receivedAt?: string;
  expectedAt?: string;
  serviceCycleHours?: number;
}
```

**初始挂点区域：**

| 区域 | 容量 | 总点位 |
|------|------|--------|
| 第1层 | 20 | 20 |
| 第2层 | 20 | 20 |
| VIP专区 | 10 | 10 |
