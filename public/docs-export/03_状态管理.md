# 03 状态管理

## 架构概述

项目使用 React Context + useState 管理全局状态，无 Redux/Zustand。所有状态通过 `AppProvider` 注入，子组件通过 `useAppStore()` hook 获取。

**文件：** `src/app/data/AppContext.tsx`

---

## AppProvider

```tsx
// App.tsx 根组件中包裹
<AppProvider>
  <div className="size-full flex">
    <Sidebar />
    <main>{ renderPage() }</main>
  </div>
</AppProvider>
```

## AppContextType 接口

```typescript
interface AppContextType {
  // 系统配置
  colors:      ColorItem[];   setColors:      (v: ColorItem[])   => void;
  brands:      SimpleItem[];  setBrands:      (v: SimpleItem[])  => void;
  defects:     SimpleItem[];  setDefects:     (v: SimpleItem[])  => void;

  accessories: PricedItem[];  setAccessories: (v: PricedItem[])  => void;

  // 商品目录

  // 会员
  members:     Member[];      setMembers:     (v: Member[])      => void;

  // 门店
  stores: Store[]; setStores: (v: Store[]) => void;

```

## 工具函数

### getMemberTier

```typescript
export function getMemberTier(
  totalSpent: number,
  tiers: MemberTier[]
): MemberTier
```

根据会员累计消费额返回对应等级。等级列表按 `minSpent` 降序排列后取第一个满足条件的等级。

### buildHookSlots

```typescript
export function buildHookSlots(
  zones: HookZone[],
  existing: HookSlot[] = []
): HookSlot[]
```

根据区域配置生成全量挂点列表。若 `existing` 中已有同区域同标签的点位则保留其状态，否则创建 `status: 'free'` 的新点位。在修改挂点区域配置时调用以重建列表。

### allocateHookSlot

```typescript
export function allocateHookSlot(
  categoryId: string,
  hookZones: HookZone[],
  hookSlots: HookSlot[]
): HookSlot | null
```

为指定品类找到第一个可用（`free`）挂点：

1. 筛选 `categoryIds` 包含该品类或为空（接受所有）的区域
2. 在匹配区域中找状态为 `free` 的点位
3. 按序号（label 末位数字）升序排列，返回最小序号的空闲点
4. 全满则返回 `null`

## 状态持久化

当前版本**不做持久化**，所有状态随页面刷新重置为初始数据。如需持久化，可在各 useState 初始化时从 localStorage 读取，在 setState 时写入。

---

## 局部状态

各页面组件内也有大量局部 useState，主要用于：

- 弹窗开关（`showXxxModal`）
- 表单输入（`formValue`）
- 选中项（`selectedId`）
- 筛选条件（`filterState`）
- 多步骤流程（`step`）

这些状态不通过 Context 传递，仅在组件内部使用。
