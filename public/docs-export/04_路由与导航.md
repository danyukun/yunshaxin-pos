# 04 路由与导航

## 路由机制

本项目**不使用 URL 路由**（react-router 已安装但未使用），采用 `currentPage` state 驱动的 switch 渲染。

```tsx
// App.tsx
const [currentPage, setCurrentPage] = useState('home');

const navigate = (page: string) => {
  setCurrentPage(page);
  setSearchQuery('');
  setOrderMember(null);
};

const renderPage = () => {
  switch (currentPage) {
    case 'home':           return <Dashboard onNavigate={navigate} />;
    case 'order':          return <ReceiveOrder ... />;
    case 'wash':           return <WashDispatch ... />;
    // ... 其余 19 个页面
    default:               return <ReceiveOrder ... />;
  }
};
```

---

## 全局状态传递

App 还维护以下跨页面状态：

| state | 类型 | 用途 |
|-------|------|------|
| `searchQuery` | string | Header 搜索栏内容，传给各页面 |
| `orderMember` | Member \| null | 从会员管理跳转到收单时携带的预选会员 |

`navigate()` 会清空这两个状态，确保切换页面时不遗留上一页的数据。

## Sidebar 收折逻辑

```tsx
// 初始：宽度 < 1024px 时自动收折
const [isSidebarCollapsed, setIsSidebarCollapsed] = useState(
  () => typeof window !== 'undefined' && window.innerWidth < 1024
);
```

收折时只显示图标，展开时显示图标+文字。

---

## Header 功能

- 搜索框：输入后更新 `searchQuery`，各页面接收后过滤数据
- 会员快速选择：搜索会员后选中，携带到收单页（`orderMember`）
- 门店切换：下拉选择当前门店（局部 state，不影响全局数据）
- 侧边栏收折按钮
