## P01 · 下单收银（ReceiveOrder）

**路由 key：** `order`  
**文件：** `src/app/components/pages/ReceiveOrder.tsx`  
**定位：** POS 核心收银台，最高频使用页面

### 核心交互流程
1. 选择客户：Header搜索框输入手机号/姓名 → 下拉选择 → 客户卡右侧显示
2. 选择订单类型：A型（自送自取）/ B型（自送配送）/ C型（上门取送）
3. 录入衣物：左侧品类 → 中间品目 → 自动生成衣物行
4. 填写衣物信息：颜色/品牌/瑕疵/附件/工艺/照片/绑标
5. 系统自动分配挂点：每件衣物实时补位算法
6. 确认收款：「收银」→ CheckoutModal → 支付方式 → 提交

### 关键状态
- `member` — 当前选中客户（null=未选）
- `garments` — 衣物行数组（含挂点）
- `orderType` — A/B/C
- `showCheckout` — 收款弹窗
- `showRecharge` — 充值弹窗

### 数据流
- 读：catalog / categories / members / hookZones / hookSlots
- 写：orders.addOrder() / hookSlots(reservation) / members(充值/地址)

## P02 · 洗护订单（ClothesStock）

**路由 key：** `clothes`  
**定位：** 全量订单管理，双栏布局（列表+详情）

### 状态分组 Tab
| Tab | 对应 phase 范围 |
|-----|----------------|
| 全部 | 所有订单 |
| 取收衣 | phase 0~4（ordered→received）|
| 洗涤中 | phase 5~12（sent_wash→packing）|
| 待交付 | phase 13~16（factory_out→delivering）|
| 已完成 | completed |
| 异常 | cancelled / compensated |

### 关键操作
- 确认自取（A型）：on_shelf → completed + 释放挂点
- 发货（B/C型）：on_shelf → delivering
- 退单：cancelled（二次确认）
- 退赔：compensated + 赔付金额

## P04 · 批次到店（PickupOrder）

**路由 key：** `arrive`  
**定位：** 工厂批次回厂后的到店入库确认

### 关键逻辑
- 搜索：批次号或客户名，Header搜索框联动
- 在途批次：sent_wash~factory_out 状态
- 确认到店：选中衣物批量 → store_in + 追踪记录
- 挂点显示：每件衣物显示已分配挂点

## P06 · 挂点管理（HookManage）

**路由 key：** `hook-manage`  
**定位：** 门店挂点总览与管理

### 点位三色状态
- 灰=空闲 / 绿=在用(含washing+ready) / 黄=超期≤3天 / 红=超期>3天

### 超期逻辑
```
超期判断 = now > warehousingAt + serviceCycleHours
黄色告警：超期 0~3 天
红色严重：超期 > 3 天
```
