# 07 挂点管理系统

## 概念说明

| 概念 | 说明 |
|------|------|
| **挂点区域**（HookZone）| 货架的一个逻辑分区，如「第1层」「VIP专区」|
| **挂点**（HookSlot）| 区域内的一个具体位置，如「第1层-3」|
| **挂点状态** | free / washing / ready / collected |

---

## 挂点状态含义

| 状态 | 说明 |
|------|------|
| `free` | 空闲，可分配 |
| `washing` | 已分配，衣物在洗涤中 |
| `ready` | 衣物已上架，等待取件 |
| `collected` | 已取走 |

---

## buildHookSlots（构建挂点列表）

```typescript
export function buildHookSlots(
  zones: HookZone[],
  existing: HookSlot[] = []
): HookSlot[]
```

**使用场景：**
- 初始化时：`INIT_HOOK_SLOTS = buildHookSlots(INIT_HOOK_ZONES)`
- 修改区域配置后重建

**算法：**
```
对每个区域：
  循环 i = 0 到 capacity-1：
    label = `${zone.name}-${i+1}`
    若 existing 中有相同 zoneId+label 的点位 → 保留原点位
    否则 → 创建新的 free 点位
```

## allocateHookSlot（自动分配挂点）

```typescript
export function allocateHookSlot(
  categoryId: string,
  hookZones: HookZone[],
  hookSlots: HookSlot[]
): HookSlot | null
```

**使用场景：** 收单时为新衣物自动推荐挂点。

**算法：**
```
1. zones = 所有 categoryIds 为空 或 包含 categoryId 的区域
2. 对每个 zone（按原始顺序）：
   free = zone 内 status='free' 的点位
   按 label 末位数字升序排列
   若 free.length > 0 → 返回 free[0]
3. 全部遍历后无空位 → 返回 null
```

## HookSlotPicker 组件

位于 `ReceiveOrder.tsx`，收单时选择挂点的 UI：

- 按区域分组显示网格
- 颜色标识：绿色=空闲，橙色=占用，灰色=已取走
- 点击空闲点位即可分配
- 显示已占用点位的衣物信息（悬停提示）

---

## HookManage 页面

路由：`hook-manage`

功能：
1. 查看所有区域及点位状态（可视化表格）
2. 新增/修改/删除区域
3. 调整区域容量（触发 `buildHookSlots` 重建）
4. 设置区域品类绑定

修改容量时，`setHookSlots(buildHookSlots(newZones, hookSlots))` 保留已占用点位的状态。

## 初始配置

```typescript
export const INIT_HOOK_ZONES: HookZone[] = [
  { id: 'z1', name: '第1层',  capacity: 20, categoryIds: [] },
  { id: 'z2', name: '第2层',  capacity: 20, categoryIds: [] },
  { id: 'z3', name: 'VIP专区', capacity: 10, categoryIds: [] },
];
// 生成 50 个挂点，全部为 free 状态
export const INIT_HOOK_SLOTS: HookSlot[] = buildHookSlots(INIT_HOOK_ZONES);
```
