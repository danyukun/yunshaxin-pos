# 08 会员系统

## 会员等级体系

| 等级 | 升级门槛（累计消费）| 折扣率 | 徽章样式 |
|------|---------------------|--------|----------|
| 普通会员 | ¥0 | 100%（无折扣）| 灰色 |
| 银卡会员 | ¥500 | 95折 | 浅灰 |
| 金卡会员 | ¥1500 | 90折 | 琥珀黄 |
| 黑卡会员 | ¥5000 | 85折 | 深黑 |

等级计算：`getMemberTier(member.totalSpent, memberTiers)`

---

## 会员字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `balance` | number | 余额（元），可用于支付 |
| `totalSpent` | number | 历史累计消费额，决定等级 |
| `isImportant` | boolean | 是否重要会员 |
| `importantLevel` | 1\|2\|3 | 重要程度（星数）|
| `isFollowWechat` | boolean | 是否关注微信公众号 |
| `storeId` | string | 注册/归属门店 |
| `addresses` | MemberAddress[] | 收货地址列表 |
| `coupons` | MemberCoupon[] | 优惠券列表 |

---

## 重要会员标记

- `isImportant: true` + `importantLevel: 1|2|3`
- 在会员列表中显示橙色星型徽章（1-3 颗星）
- 可在会员管理页面设置/修改
- 用于筛选高价值客户

---

## 充值

- 前台充值：`RechargeManage` 页面
- 快速充值：`ReceiveOrder` 中的 `QuickRechargeModal`（收单时直接充值）
- 充值后更新 `member.balance`
- 套餐充值：如「充200送20」（需在营销管理中配置）

---

## 优惠券

```typescript
interface MemberCoupon {
  id: string;
  name: string;       // 如 "满100减20"
  amount: number;     // 抵扣金额
  minSpend: number;   // 使用门槛
  expiry: string;     // 过期日期 YYYY-MM-DD
}
```

- 结账时可选择使用一张优惠券
- 使用后从 `member.coupons` 中移除

---

## 地址管理

```typescript
interface MemberAddress {
  id: string;
  label: string;      // 如 "家", "公司"
  address: string;
  phone: string;
  isDefault: boolean; // 每个会员最多一个默认地址
}
```

- B/C 型订单收单时从会员地址中选择
- 可在会员详情页管理（增删改、切换默认）

## 结账逻辑（CheckoutModal）

结账时支持以下支付方式（可组合）：

| 方式 | 说明 |
|------|------|
| 余额支付 | 扣除 `member.balance`，更新 `totalSpent` |
| 现金 | 记录金额，无系统操作 |
| 扫码（微信/支付宝）| 记录金额，无系统操作 |
| 混合支付 | 多种方式叠加，合计等于应付金额 |

支付完成后：
1. 创建新订单（`addOrder`）
2. 若使用了优惠券，从会员中移除该券
3. 更新会员 `totalSpent`（可能触发等级升级）
4. 打印收衣单 + 衣物标签

## 会员搜索

收单页 `ReceiveOrder` 支持两种方式关联会员：
1. **Header 搜索**：全局搜索框输入手机号/姓名，选中后通过 `orderMember` prop 传入
2. **收单页内搜索**：在 Step1 组件内直接搜索，`members.filter` 匹配 phone 或 name

会员列表页支持多维度筛选：
- 归属门店
- 是否会员（有余额 / 无余额）
- 等级（普通/银卡/金卡/黑卡）
- 重要标注（1-3星）
- 是否关注微信
