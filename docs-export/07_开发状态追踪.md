## 前端原型阶段限制说明

以下为原型阶段的已知限制，接入真实后端前均无法完全实现：

1. **数据持久化**：所有数据存储在 React Context（内存），刷新页面全部重置
2. **多设备同步**：无实时同步，每个浏览器标签页数据独立
3. **支付真实性**：点击收款不会实际扣款，仅更新本地状态
4. **打印功能**：打印按钮无实际打印指令
5. **照片存储**：照片为本地 blob URL，无法在其他设备查看
